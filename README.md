# Flash Chords

ランダムに鳴るコードを聞いて、ルート音とコードタイプを当てる耳トレーニングWebアプリ。
静的サイトで、サーバー不要・データ永続化なし(セッションはメモリ上のみ)。

- 1セッション10問(100点満点) / 1問10点からの減点式採点(下記「採点ルール」)
- Web Audio API による加算合成(外部音源ファイルなし)
- Vite + React + TypeScript、テストは Vitest

## セットアップ

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # ユニットテスト
npm run build      # 型チェック + 本番ビルド(dist/)
npm run preview    # ビルド結果の確認
```

## スマホで確認する

PC とスマホを同じ Wi-Fi に接続し、`--host` 付きで起動します。

```sh
npm run dev -- --host
```

表示された `Network: http://192.168.x.x:5173/` をスマホのブラウザで開きます。

- iOS Safari ではマナーモード(消音スイッチ)がオンだと Web Audio の音が出ないことがあります。オフにしてください。
- 音声は「セッション開始」タップ時に有効化されます。

## コード種類の追加

`src/core/chords.ts` の `CHORD_TYPES` に1行追加するだけで、出題・回答ボタン・採点・再生に反映されます。

```ts
{ id: '6', label: '6', intervals: [0, 4, 7, 9] },
```

`intervals` はルートからの半音数(ルート=0)。12以上を指定すると1オクターブ上の音になります(add9 は 14)。

## 構成

```
src/core/        UI非依存のロジック(コード定義、ボイシング、出題、採点、セッション状態)とテスト
src/audio/       Web Audio による和音再生
src/components/  画面コンポーネント
```

## 難易度

セッション開始前に、トップ画面で難易度を選びます。難易度に応じて、出題されるコードタイプと回答ボタンのタイプが絞られます(ルートは常に12音)。

| 難易度 | 出題タイプ |
|---|---|
| 入門 | Major, minor |
| 中級1 | 7, maj7, m7, m7b5 |
| 中級2 | dim, aug, sus4, add9 |
| 上級1 | 全タイプ |

難易度の定義は `src/core/difficulty.ts` の `DIFFICULTIES` を編集します。`chords.ts` に新しいコードタイプを追加したときは、上級1には自動で含まれます。それ以外の難易度で出題したい場合は、該当する難易度の `typeIds` にタイプIDを追加してください。

## 採点ルール

1問は10点から減点します。減点は独立に加算し、最低点は0です。10問の合計は100点満点で、結果画面は `85 / 100` の形式で表示します。

| 項目 | 減点 |
|---|---|
| ルート不一致 | -4 |
| タイプ不一致 | -3 |
| 構成音の不一致 | 1音ごとに -1 |

構成音の比較は**ルート相対**(インターバル集合。`add9` の14は2として扱う)で行うため、ルートの違いは構成音の減点に混ざりません。不一致数は `max(不足, 余分)` で数え、音が1つ入れ替わっただけなら -1 です。

| 正解 | 回答 | 得点 |
|---|---|---|
| C Major | C Major | 10 |
| C Major | D Major | 6 (ルート -4) |
| C Major | C minor | 6 (タイプ -3, 構成音 -1) |
| C Major | C7 | 6 (タイプ -3, 構成音 -1) |
| C m7 | C m7b5 | 6 (タイプ -3, 構成音 -1) |
| C Major | D minor | 2 (ルート -4, タイプ -3, 構成音 -1) |
| C Major | D m7b5 | 0 (ルート -4, タイプ -3, 構成音 -3) |

## 楽譜表示

回答直後と、復習画面の「楽譜を見る」で、正解コードと回答コードの構成音を楽譜で確認できます(VexFlow で SVG 描画。楽譜を初めて開くときに読み込みます)。

- 大譜表で表示します。ボイシングは再生と同じで、C4(MIDI 60)以上がト音譜表、未満がヘ音譜表です。
- 音名はシャープ表記です(`m7b5` の b5 などは異名同音のシャープで表示されます)。
- 採点と同じルート相対の基準で色分けします。正解側の「不足」はオレンジ、回答側の「余分」は赤で、音名ラベルにも「不足」「余分」を併記します。ルートが違うときは、回答のルート音に「ルート違い」と表示します。

## 結果画面の集計

合計点の下に、ルートとタイプの正答数、間違えたタイプ(出題コード側のタイプごとの「間違えた回数 / 出題数」)を表示します。集計はセッション中のメモリ上だけで持ち、新しいセッションで破棄されます。

## 聞き取りの補助

絶対音感がなくても耳を合わせられるよう、出題画面に補助機能があります。**補助は採点に影響しません。** 回答前に使った回数だけを数え、結果画面に「補助の使用: 基準音 3回 / 分散 2回 / 単音 5回」と表示します(使っていなければ非表示)。回数はメモリ上のみで、新しいセッションで0に戻ります。

- **基準音**: 「A 440Hz」「A 220Hz」ボタンで、その高さの純音を約3秒鳴らします。鳴っている間にもう一度押すと止まります。
- **分散して聞く**: 出題コードの構成音を、低い音から順に0.3秒間隔で鳴らします。復習画面と回答後の楽譜の各コードにも「▶ 分散」があります(回数には数えません)。
- **音名タップで単音再生**: ルートの音名ボタンを押すと、その音(C3〜B3)を約1.5秒鳴らします。出題画面のスイッチで切り替えます。**初期状態はOFF**で、設定は保存されず、ページを再読み込みするとOFFに戻ります。
- 復習画面と回答後の楽譜では、構成音の音名ラベルを押すと、その音を単音で鳴らせます(スイッチとは無関係。回数には数えません)。

音は常に1つだけ鳴り、新しく鳴らすと前の音は止まります。
